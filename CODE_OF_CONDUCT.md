# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our Pledge

We pledge to act and interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy community.

## Reporting

Report unacceptable behavior to the project maintainer via a private GitHub message or by opening a private security advisory on this repository. All complaints will be reviewed and investigated promptly and fairly.

## Enforcement Guidelines

Maintainers will follow the [Contributor Covenant Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) when determining the consequences for any violation.
